# AI Agent Engineering from First Principles

A hands-on course for building AI agents from scratch, covering fundamentals through advanced topics.

## Structure

- **Module 0**: Setup and verification
- **Module 1**: LLM APIs
- **Module 2**: Agent loop
- **Module 3**: Tools
- **Module 4**: Filesystem
- **Module 5**: Coding agent
- **Module 6**: Context engineering
- **Module 7**: Evals

## Getting Started

```bash
bun install
bun run verify
```

## Running Modules

```bash
bun run m1:raw    # Module 1
bun run m2:loop   # Module 2
# ... through m7
```

To run your own code:

```bash
bun module-N/my-file.ts
```

### Python

```bash
pip install -r requirements.txt
python module-N-topic/solutions/python/file.py
```
